# Store setup – Hoodies, Sweatshirts & Graphic Tees

Your theme is built around **hoodies**, **sweatshirts**, and **graphic/custom t‑shirts**. Follow these steps so the store works and you only need to add products.

---

## 1. Create collections

In **Shopify Admin → Products → Collections**, create these three collections (handles must match exactly):

| Collection title   | Handle (URL)   |
|--------------------|-----------------|
| Hoodies            | `hoodies`       |
| Sweatshirts        | `sweatshirts`   |
| Graphic Tees       | `graphic-tees`  |

- **Hoodies** – add all hoodie products.  
- **Sweatshirts** – add all sweatshirt / crewneck products.  
- **Graphic Tees** – add all graphic and custom t‑shirts.

You can use **Manual** or **Automated** (e.g. by product type or tag).

---

## 2. Homepage collections

- **Sponsored picks** (first product grid) uses the **Homepage** / **frontpage** collection.  
  - In **Admin → Online Store → Themes → Customize → Homepage**, open the **“Sponsored picks”** section.  
  - Set **Collection** to the collection you want to feature there (e.g. “Homepage” or a “Featured” collection).  
- **Hoodies**, **Sweatshirts**, and **Graphic & custom tees** sections are already set to use the collections with handles `hoodies`, `sweatshirts`, and `graphic-tees`.  
  - After you create those collections (step 1), the homepage will show products from them.

---

## 3. Sponsored / affiliate products (best position for ads)

The **“Sponsored picks”** section is the main place for sponsored/affiliate items:

- It appears **right after the hero and trust marquee**, so it’s one of the first things visitors see.
- Use the **Product links** blocks in that section to set a product and link (e.g. Amazon or any URL) for each slot.
- Click a product card in the theme editor to open that slot’s link settings.

To add or change sponsored links:

1. **Customize** the theme → open the **“Sponsored picks”** section.  
2. Under **Product links**, use **Add block** (or the existing blocks).  
3. For each block: choose **Product** and set **Link URL**.  
4. The first 8 products in the section’s collection use blocks 1–8; set links for as many as you need.

---

## 4. Navigation

The header is set to:

- **Hoodies** → `/collections/hoodies`  
- **Sweatshirts** → `/collections/sweatshirts`  
- **Graphic Tees** → `/collections/graphic-tees`  
- **Shop All** → `/collections/all`  

If you use different collection handles, update **Theme settings → Header** (or the header section) so the nav URLs match your handles.

---

## 5. What’s left for you

- **Add products** to the three collections (and optionally to the collection used for “Sponsored picks”).  
- **Upload a hero image** (Theme customizer → Hero) that fits hoodies/sweatshirts/tees.  
- **Set your logo** in Theme settings → Header.  
- **Add Privacy / Terms / Contact** pages and link them in the footer if you use menus there.  
- **Optional:** Create a **Featured** or **Homepage** collection and assign it to “Sponsored picks” for a dedicated sponsored/affiliate lineup.

Once the three collections exist and have products, the store is ready to use; the rest is adding and organizing products and optional content.
